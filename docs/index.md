# 📚 О базе знаний

Для производства качественных программных продуктов в согласованный срок и без превышения бюджета нужна система 
управления производством, которая преобразует разработку из творческого хаоса в управляемый, предсказуемый и повторяемый 
процесс производства. Современные технологии в обозримом будущем позволят эволюционировать текущим системам управления в 
автоматизированные системы управления производства программных продуктов. 

Фундаментом любой системы управления являются актуальные, зафиксированные знания и опыт. Причем, такая система требует 
наличия единого источника истины. 

База знаний создается автором как инструмент для накопления знаний и опыта, имеющихся у автора. Текущие цели базы знаний
сформулированы следующим образом:

- **Накопление и систематизация информации**: Собрать и постоянно актуализировать информацию, необходимую для 
выстраивания процессов системы управления производством программных продуктов. 
- **Полигон для исследований**: Использовать базу знаний как "полигон" для исследования способов создания и ведения 
документации для системы управления производством программных продуктов и для самих программных продуктов: порядков 
действий, требования к программному продукту, инструкции пользователя и других документов.
