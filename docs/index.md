# 📚 О базе знаний

Для производства качественных программных продуктов в согласованный срок и без превышения бюджета нужна система 
управления производством, которая преобразует разработку из творческого хаоса в актуализирумый, управляемый, 
предсказуемый и повторяемый процесс производства. 

Фундаментом любой системы управления являются знания и опыт работников производящей компании. Причем, такая система 
требует наличия единого источника истины. 

База знаний создается автором как инструмент для накопления информации, необходимую для выстраивания процессов системы 
управления производством программных продуктов.

Так же база знаний используется как "полигон" для исследования способов создания и ведения документации для системы 
управления производством программных продуктов и для самих программных продуктов: порядков действий, требований к 
программному продукту, инструкций пользователя и других документов.
