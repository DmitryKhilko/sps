# О базе знаний

Я работаю в сфере производства программных продуктов. В том или ином объёме "примерил" на себя роли: руководителя 
проекта, аналитика, программиста, тестировщика, администратора + техподдержки. Периодически приходилось совмещать 
несколько ролей.

За время работы принял участие в 17 проектах производства/внедрения программных продуктов (от микропроектов, 
автоматизирующих отдельные бизнес-функции, до проектов масштаба страны):

- 14 проектов были успешны;
- 2 внутренних проекта не дошли до прода из-за отказа от них руководства; 
- 1 проект закончился провалом: уже при эксплуатации на проде Заказчик потребовал проект передать другой компании. 

Слово "производство" в отношении к программному продукту использую намерено. Разработка программного обеспечения все 
больше становится похожей на производство традиционных товаров. 

К тому же, современные технологии в обозримом будущем позволят создать автоматизированные системы производства 
программных продуктов (аналог производственного конвейера товарных заводов). Появление таких систем - неизбежность, 
которая диктуется компаниям конкуренцией и экономикой (сокращением затрат). 

Получаемый мной опыт показал: для минимизации вероятности провала при производстве программных продуктов нужна система 
управления производством, которая сможет преобразовать разработку из творческого хаоса в управляемый, предсказуемый и 
повторяемый процесс. 

Тем более, переходить к автоматизированной системе производства программных продуктов без наведения порядка в каждой 
"ручной" производственной операции - бессмысленно. Автоматизация хаоса породит только автоматизированный хаос.

Отсюда текущие цели базы знаний: 

- Накопление и систематизация информации, необходимой для построения процессов производства программных продуктов, 
гарантирующих поставку Заказчику качественного продукта в согласованный срок без превышения бюджета.
- База знаний является "полигоном" для исследований способов создания и ведения документации для системы производства 
программных продуктов и для самих программных продуктов: порядков действий, требований к программному продукту, 
инструкций пользователя и т.д.
