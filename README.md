# О базе знаний

## Опыт автора базы знаний

Автор базы знаний Дмитрий Хилько работает в сфере производства программных продуктов. В том или ином объёме "примерил" 
на себя роли: руководителя проекта, аналитика, программиста, тестировщика, администратора + техподдержки. Периодически 
приходилось совмещать несколько ролей.

Автор участвовал в 17 проектах производства и внедрения программных продуктов: от микропроектов, автоматизирующих 
отдельные бизнес-функции Заказчика, до проектов масштаба страны. Итоги проектов:

- **Успешные проекты**: 14 проектов.
- **Остановленные проекты**: 2 внутренних проекта не дошли до промышленной эксплуатации из-за отказа руководства от их 
продолжения.
- **Неуспешный проект**: 1 проект. При эксплуатации в промышленной среде Заказчик потребовал передать проект другой 
компании-разработчику.

## Подход: производство программных продуктов

Автор базы знаний использует Слово "производство" в отношении к программному продукту. По наблюдению автора, разработка 
программного обеспечения всё больше становится похожей на производство традиционных товаров. 

По оценке автора, современные технологии в обозримом будущем позволят создать автоматизированные системы производства 
программных продуктов, аналогичные производственным конвейерам товарных заводов. Причины, по которым компании придут к 
таким системам: конкуренция и сокращение затрат.

Опыт автора показывает: для снижения вероятности провала при производстве программных продуктов нужна система 
управления производством, которая преобразует разработку из творческого хаоса в управляемый, предсказуемый и 
повторяемый процесс производства. 

Тем более, переход к автоматизированной системе производства программных продуктов не имеет смысла без наведения порядка 
в каждой "ручной" производственной операции: автоматизация хаоса даёт только автоматизированный хаос.

## Цели базы знаний

Поскольку фундаментом любой предсказуемой системы управления и наведения порядка в операциях являются актуальные, 
зафиксированные стандарты и опыт, возникает необходимость в едином источнике истины. Данная база знаний создается 
автором как инструмент для структурирования этого фундамента, а её текущие цели сформулированы следующим образом:

- **Накопление и систематизация информации**: Собирать информацию, необходимую для построения процессов производства 
программных продуктов. Процессы должны обеспечивать поставку Заказчику качественного продукта в согласованный срок и без 
превышения бюджета.
- **Полигон для исследований**: Использовать базу знаний как "полигон" для исследования способов создания и ведения 
документации для системы управления производством программных продуктов и для самих программных продуктов: порядков 
действий, требования к программному продукту, инструкции пользователя и других документов.
